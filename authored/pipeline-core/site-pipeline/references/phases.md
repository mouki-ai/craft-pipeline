# Phases in full

Each phase has an output that the next phase consumes. A phase is not done because work happened in it; it is done when its output exists and the user has seen it.

## 0. Intake
Output: a brief on one screen — who the visitor is, what they should do, what the offer is, what must not appear, deadline and budget.
Ask one question at a time. Never start the design while the brief is still a guess.

## 1. Architecture
Output: one chosen architecture, stated in plain words with its consequence for the client.
Static landing page, CMS-backed site, or app with a real backend. Choosing late is the expensive mistake in this pipeline.

## 2. Direction
Output: a written art direction — palette with roles, type pairing and scale, spacing rhythm, motion rhythm, imagery treatment, and for each reference what is being borrowed and what is being changed.
This is the phase that decides whether the result looks like everyone else's. Spend the time here, not in Phase 4.

## 3. Structure and copy
Output: an ordered section list, each with a goal, and real copy — not lorem, not placeholder headlines.
One primary call to action for the whole page. Every section either moves toward it or is cut.

## 4. Build
Output: implemented sections, each reviewed in the real page at real widths.
Build in the order of the section list. Do not animate anything yet: motion on top of a wrong layout hides the wrongness.

## 5. Motion
Output: motion that a reviewer can describe without watching it twice, plus a working reduced-motion path.
Scroll choreography before micro-interactions. Every animation has a reason stated in one sentence.

## 6. Media and 3D
Output: video, imagery and WebGL scenes that hold their frame budget on the weakest target device.
Measure before adding the second effect. A hero that stutters is worse than a hero that is still.

## 7. QA
Output: a full-page review, an accessibility pass, a performance pass, and an originality check against the references from Phase 2.
Per-section approval does not add up to a finished page. Review the whole thing again, in one sitting, at three widths.

## 8. Ship
Output: a live URL, a known rollback, and a short case-study capture if the work is portfolio-worthy.
